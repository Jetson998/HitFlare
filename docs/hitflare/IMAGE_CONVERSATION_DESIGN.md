# 出图的两个方向

图片创作和创作 Agent 分开。方向 2 已恢复为绘画面板。方向 1 的页面已有左侧会话和方案卡，旅程尚未按下面的约定收口。本文记录已确认的交互，不作为已实现说明。

## 方向 1：创作 Agent

这是多轮对话。生图先给方案卡，人确认完才生成。

人可以来回补充需求。目标不够时，Agent 只在对话里追问必要的创作问题，不出方案卡，也不出图。目标清楚后，只出现一张当前方案。旧方案不再各自出图。

人可以改这张卡上的目标和提示词。输入框下方有一颗小按钮，点开先选 Agent 模型，再选图像模型、比例、清晰度和张数。按钮上只显示图像参数短摘要。输入框旁不再单独透出文本模型。参数不铺进对话，也不放在方案卡上。

确认动作是「使用方案」。没点之前，不向模型要图。出图中只有一个停止。此时输入框和旧卡不能再发起一轮付费生成。刷新不取消正在出的这一轮。

图出来之后如果要改，还是先说话，再得到一张新的方案卡，再次确认后才生成。下一句不直接拿去改图。

不改 `/image` 的三栏。不新增超时、重试、大小或并发默认值，沿用现有图片生成任务。

## 方向 2：图片创作

`/image` 保持绘画面板。

宽屏三栏：左侧是提示词、参考图、场景模板和生成设置；中间是生成结果；右侧是生成记录。窄屏隐藏右侧记录，从顶部按钮打开。

这里不放 Agent 对话，不把结果收成聊天气泡。人自己写提示词、选参数、点开始生成。

## 边界

| 入口 | 形态 | 不做什么 |
| --- | --- | --- |
| 创作 Agent | 多轮对话，方案确认后出图 | 不替代绘画面板，不把原话直接交给生图接口，不在未确认时出图 |
| 图片创作 | 绘画面板 | 不改成对话 |
| 无限画布 | 节点编排 | 不并进出图对话 |
| 反推提示词 | 从图片提取提示词 | 不并进 Agent 对话 |

## 已按旅程收口

输入框下方的图片参数小按钮里，先选 Agent 模型，再选图像模型、比例、清晰度和张数。输入框旁不再单独透出文本模型。只有最新方案可以点使用方案。出图中输入框变为停止，不能再发对话或从旧卡出图。刷新仍不取消正在出的图。目标是否足够清楚仍由文本模型判断，不是代码强制关卡。
