## 0. 这轮不改

- 不重画创作 Agent 的气泡、方案卡和输入结构。
- 不重画画布编辑器，也不收画布编辑器里的弹窗宽度。
- 不引入 Ant Design X，不把它的默认紫皮套到创作 Agent。
- 不把全站收成一种样子。列表页不要改成聊天气泡，工作台和配置不要改成紫色主按钮。
- 不新做空状态插画、品牌动效、卡片上浮。
- 不新做视频灯箱，不拦截浏览器前进后退手势。
- 登录不退回白卡片。首页不改品牌结构。

## 1. 基础样式

两套外观分开用。字号、间距、圆角在宽屏和窄屏共用，窄屏不另写一套字号。

### 1.1 字号

不下载新字体，不加全局字距。首页品牌标题已有的轻微负字距只留在首页。15px 这一档取消，收回下表。现在灵感分类和设置面板里的 15px，外观批次再改，窄屏批次不动。

| 用途 | 字号 / 行高 | 字重 | 用在哪 |
| --- | --- | --- | --- |
| 首页品牌标题 | 宽屏 48 / 60，窄屏 32 / 42 | 600 | 只在首页品牌区 |
| 首页区域标题 | 24 / 32 | 600 | 只在首页 |
| 列表页标题 | 18 / 26 | 600 | 资产、灵感、用户、存储；日志保留现有 16px |
| 分组、弹窗、抽屉标题 | 16 / 24 | 600 | 列表和后台弹层 |
| 资产详情标题 | 16 / 24 | 600 | 只在资产详情 |
| 导航、列表正文、一级页签 | 14 / 22 | 400，选中 600 | 列表页和导航 |
| 说明、按钮、表单、气泡 | 13 / 20 | 400，按钮 500 | 两套外观都用 |
| 日期、数量、底部操作 | 12 / 18 | 400 | 辅助信息 |

工作台、反推、创作 Agent、配置不出现 18px 页面标题。管理日志标题保持已发布的 16px，筛选和表格 13px，不升回 18px。

### 1.2 间距

只使用这些间距。不按页面临时加 10px、14px、18px。

| 间距 | 用在哪 |
| --- | --- |
| 4 | 标题和说明 |
| 6 | 图标和文字；表单标签和输入 |
| 8 | 同组按钮 |
| 12 | 工具条换行后的间距 |
| 16 | 标题区到下一行；筛选到内容；卡片间距；表单项 |
| 20 / 24 | 页面上边距 / 下边距 |

页面左右边距用已发布的 `clamp(24px, 2cqi, 48px)`。窄屏顶栏左右留白至少 24px，左边距和页面内容对齐。规范旧稿里的 16px 最小边距作废。

长说明最宽约 70 个字符。单列表单最宽 640px。这两条不套到整页上。宽屏不设全站最大宽度。首页内容区仍最宽 1320px，只限首页。画布列表的 `max-w-6xl` 先标成例外，这轮不重排。

### 1.7 两个品牌例外

不收进上面两套，也不要扩散。

- 首页主按钮保持现在的紫色、高 44px。不收成 32px，也不改成黑胶囊。
- 登录按钮保持 `#FF6B35`，悬停 `#F45B28`，高 44px。这不是第三套组件皮肤。

### 1.8 图标

继续用 Lucide。导航和工作台图标 16px，列表工具图标 14px。灯箱里已经在用的 Ant Design 图标先保持，不强制换成 Lucide。不新增图标库。

窄屏的返回是 36px 圆、20px 箭头。它是导航，不是 32px 的轻操作白圆。两档不要并成一档。

### 1.9 手感

两套外观共用：

- 悬停只换底色或边框色，大约 150 毫秒。
- 按下不位移，不加放大。
- 键盘焦点是 2px 实线，向外偏 2px。列表用主按钮色。工作台浅色用 `#111827`，深色用 `#FFFFFF`。不要用现在输入框那种很淡的紫色阴影当焦点。
- 原稿“所有禁用控件整体降到 40%”已撤回。禁用表面、字色、边界分别定义，保持可辨识；见视觉复审。
- 遵守系统的「减少动态效果」。打开后，悬停位移和循环晃动都停。

创作 Agent 已经定过、不要重画的：点标题时图形先压扁再弹起，箭头从右侧滑出；思考或出图时图形左右轻晃，不用转圈代替；输入没内容时是一行，写了字或加了图后高度固定，文字在框内滚动，图片在文字上方。

不纳入：页面切换动画、滚动惯性、音效、卡片上浮、蓝色投影、新的品牌动效。

### 2.1 列表页

图：[design/list-page.svg](design/list-page.svg)

适用：资产、灵感、用户、日志、存储。配置不套这个模板。

宽屏：左侧竖栏。标题 18px，主操作在标题行右侧。搜索和筛选在下一行。内容用网格或表格，不限全站宽度。卡片间距 16px。

窄屏，内容库：去掉搜索、数量、更多操作和宫格切换。保留「全部资产 / 上传素材 / 生成结果」和「我的收藏」，允许换行。只显示现在的时间轴，日期仍是「2026年10月31日 · N 项」。不再按模态筛选。点图片走轻度预览。文字、视频、音频仍进原来的详情。判断宽度用页面容器，不用窗口宽度。

上段“点图片走轻度预览”是已确认目标，当前线上窄屏仍出现审读操作，尚待开发核对部署产物。现网卡片保留标题、来源、类型和操作，不按旧样图改成两列纯图片。

窄屏，创作灵感：不显示搜索。分类标题和「查看全部」保留。封面写死两列，用现有紧凑卡片，只留封面和标题。不能靠最小 240px 的自动网格，360px 左右仍会落成一列。「查看全部」进去也是两列，返回回到分类总览。

窄屏，管理日志：不套内容库时间轴。筛选保持已发布的下拉换行，不再恢复五列网格。表格在表格内部横滑。

## 5. 弹层

窄屏铺满或改画廊的，用视口 767px，因为弹层读不到页面容器。页面内部的隐藏和换列仍用容器宽度。

### 5.1 原宽度归并提案（暂不执行）

以下为旧稿候选，未作为开发尺寸决策。视觉复审保留模型参数 440px、参考图选择资产 760px 等现有宽度；先核对字段与内容密度，再决定是否归并。

| 档 | 宽度 | 用在哪 | 窄屏 |
| --- | --- | --- | --- |
| 模型配置 | `min(440px, calc(100vw - 32px))` | 图片、视频、反推、Agent 的模型参数。已发布，不并入 480 | 仍居中，内容在弹窗内滚动 |
| 短确认 | 480 | 外链确认这类短内容。现在的 420 外观批次并入 | 不超过视口，左右留 16px |
| 表单 | 640 | 渠道抽屉、来源抽屉、日志详情、中等表单 | 视口 767px 以下铺满。标题单独一行，取消和保存放到底部 |
| 详情 | 720 | 创作灵感详情 | 铺满视口。封面上，提示词滚动，复制和加入资产固定在底部 |

来源抽屉现在是 560，日志详情现在是 600。原并入 640 的提案暂不推进，先验证字段和内容密度。画布编辑器里的 760、780、820、860、980 不收，也不改。

参考图的选择资产保持现有结构：来源页签加「我的收藏」，按日期滚动加载，点图是轻度预览，添加是贴在图内底部的浅黑胶囊，大约 70% 宽。它没有搜索。宽屏保持现有 760，原并入 720 的提案暂不推进。画布、视频、反推的选择资产仍按类型翻页，并保留搜索，不和这一套画成同一个。

### 5.2 两种预览，不要画成一种

都全屏、居中。点空白或 Esc 关闭。翻转、旋转、缩放、拖动只作用于预览，不改原图。放大后的拖动只用来移动画面。

| | 审读预览 | 轻度预览 |
| --- | --- | --- |
| 用在哪 | 图片创作结果、Agent 方案图、画布生成图 | 参考图、内容库图片 |
| 遮罩 | `rgba(0, 0, 0, 0.92)` | `rgba(0, 0, 0, 0.60)` |
| 右上 | 收藏、下载、存入资产、关闭 | 只有关闭 |
| 宽屏多图 | 保留左右按钮 | 不使用左右按钮 |
| 窄屏多图 | 底端缩略图 | 底端缩略图 |

窄屏规则，两套相同：

- 只有一张图时，不显示画廊。
- 多张图时，底端一排缩略图，可以横滑。当前这张用现有选中框标出。点一张就切到那张。
- 顶部的「1 / 3」保留。
- 不画左右按钮，也不要左右滑动切图。屏幕边缘的横滑容易被浏览器当成前进、后退。
- 翻转、旋转、缩放仍是原来的按钮，放在画廊下面单独一行，超出后横滑，不收成「更多」。

内容库窄屏直接预览和资产详情中的图片放大已在本地源码使用轻度预览，前端反馈开发完成；当前核对的发布包中，窄屏直接预览仍出现审读操作。这项继续保留为发布与验收差异，见现网核对记录，不能按本地源码判定线上已经通过。

## 6. 会话头像

目标是用户指定的黏土机器人风格。现有 `AgentBotMark` 是简化色块，不能作为最终材质示例；按会话稳定分配造型本身不违背“同一会话一致”。

目标从 Grok Bot Studio 导出，不在仓库里重画一个「像黏土」的替代图。替代图会被当成正式素材。

- 链接：<https://grokbots.ai/studio?face=excited&shape=cloud>
- 指定形状为云朵、表情为兴奋。颜色尚未定稿，不把“所有会话统一蓝色”写成已确认要求。
- 导出 512×512 透明 PNG，或 SVG。
- 同一会话只用这一张。历史、标题胶囊、等待文案旁都用它。
- 思考或出图仍用现有的左右轻晃。不导入 Studio 的 15 个动作，也不要求光标跟随。

正式素材示例尚未交付，任务保持未完成；样稿中的占位形状不作为最终头像。
