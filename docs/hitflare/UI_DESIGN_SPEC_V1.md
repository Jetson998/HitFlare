# HitFlare 前端 UI 统一规范 · V1

状态：历史草案，已由 [V2 完整方案](UI_IMPLEMENTATION_PLAN_V2.md) 替代。下文保留用于追溯；其中统一 1280px 最大宽度和固定 24px 外侧边距已被否决，不作为开发依据。

## 1. 设计方向与取舍

方向：白色主体、黑色文字、紧凑操作区、清晰内容层级，少量蓝紫色表达主操作和选中状态。科技感来自精确对齐、统一尺寸和清楚的交互反馈。

HitFrame 参考的是设计方法，具体参数按 HitFlare 的现有功能、可读性和内容密度重新确定。

| 本地参考依据 | 可采用的做法 | HitFlare 的调整 |
| --- | --- | --- |
| `HitFrame/apps/web/src/index.css` | 颜色、圆角、阴影集中定义；白色面板与深色正文 | 页面主体统一白色；浅灰只用于局部状态与占位；不照搬灰色工作区 |
| `HitFrame/apps/web/src/components/ui/button.tsx` | 主按钮、次按钮、轻操作分工；紧凑按钮为 32px | 工具页面默认用 32px，而非其默认 40px；不让每个按钮都带扩散阴影 |
| `HitFrame/apps/web/src/pages/AssetsPage.tsx` | 标题与主操作同一层，筛选独立；图标 13–16px | 标题采用 18px，提高可读性；筛选、搜索外框统一 32px，修正参考页本身 32/40px 混用 |
| `HitFrame/apps/web/src/pages/GeneratePage.tsx` | 设置区紧凑、主要生成操作突出 | 保留 HitFlare 两个一级页签、参考图统一输入、右侧记录和折叠设置 |

品牌名、Logo、口号沿用已确认内容。品牌 KV 的橙金色用于 Logo 和品牌图片，工作台正文不染色；既有 KV 文档不作为页面灰底、深底或大字距的依据。

## 2. 现状问题

- 早期版本曾给首页、导航和配置使用不同固定容器，造成相同层级左边界不一致；该问题已由 V2 的流式容器处理。
- 资产筛选与搜索使用 `size="large"`，分段筛选还叠加内边距；工具区没有统一的最终外框高度。
- 标题说明之后连续叠加 24px 间距、工具区底部内边距和内容上方间距，首屏留给内容的面积减少。
- 页面操作、卡片操作和输入框混用不同尺寸，圆角和阴影也没有按用途分级。
- 上轮的白底和局部排版调整不等于全站规范已完成；所有菜单及其弹窗都要纳入下一轮清单。

所有尺寸均指 CSS 像素、浏览器缩放 100% 时的布局值；不通过缩放页面修正排版。

## 3. 全局布局与间距

| 项目 | 桌面规范 | 说明 |
| --- | --- | --- |
| 常规内容容器 | 使用 V2 的流式边距，不设置全站最大宽度 | 首页、资产、灵感、配置、用户管理与顶部导航共用 |
| 页面顶部 / 底部间距 | 20px / 24px | 标题从顶部间距之后开始，不重复添加外层 padding |
| 标题与说明间距 | 4px | 说明仅一段，不增加装饰性副标题 |
| 页头与筛选 / 页签间距 | 16px | 没有筛选时，页头直接与内容相隔 16px |
| 筛选与内容间距 | 16px | 不叠加多层 margin、padding 和分隔线留白 |
| 内容分组间距 | 24px | 同一组内使用 12px 或 16px |
| 卡片网格间距 | 16px | 卡片文字区内边距 16px |
| 同组操作间距 | 8px | 图标与文字间距 6px |
| 搜索宽度 | 320px | 空间不足时换行并占满可用宽度 |
| 标准表单宽度 | 单列最大 640px | 页面外层继续流式扩展，表单保持可读宽度 |

桌面资产页从内容区顶部到网格起点约 134px：20px 顶部 + 50px 标题说明 + 16px 间距 + 32px 筛选行 + 16px 间距。说明换行时自然增高，不固定高度裁切。

图片创作采用全宽工作区，以便展示结果，这是用途明确的例外：左右设置 360px、记录 280px，中间自适应；可用宽度达到 1440px 时设置 400px、记录 300px。分栏内边距 20px；不足 1100px 时记录收进抽屉，设置和结果上下排列。断点按实际可用内容宽度计算，包含 Agent 面板打开后的情况。

## 4. 字体与图标

| 层级 | 字号 / 行高 | 字重 / 颜色 |
| --- | --- | --- |
| 常规页面标题 | 18 / 26px | 600，正文黑；资产、灵感、配置、用户管理一致 |
| 分组标题、弹窗标题 | 16 / 24px | 600，正文黑 |
| 导航、一级页签、正文 | 14 / 22px | 普通 400，选中或重点 500–600 |
| 说明、表单标签、按钮、搜索与筛选文字 | 13 / 20px | 说明为次级色，交互文字保持黑色 |
| 日期、数量、辅助信息 | 12 / 18px | 次级色；普通说明不使用更小字号 |
| 首页品牌主标题 | 桌面 48 / 60px，窄屏 32 / 42px | 600；只在品牌区域使用 |
| 首页区域标题 | 24 / 32px | 600；品牌 → 创作灵感 → 场景 |
| 首页品牌说明 | 16 / 26px | 次级色 |

沿用系统无衬线字体栈，不下载新字体，不增加全局字间距。

- 导航图标 16×16px；标准按钮、搜索、筛选图标 14×14px；生成主操作图标 16×16px。
- 全站采用现有 lucide 图标体系，描边 1.75px；图标与文字垂直居中，不用逐页负 margin 补偿。
- 顶部导航保持 56px，菜单文字 14px；图标按钮点击框 32×32px。过高问题优先从页面工具控件解决，不压缩已验收 Logo。
- 顶部 Logo 保持已确认的 42px 图片高度和上移 4px。它是图片内部字标对齐的明确例外，不用于普通图标。

## 5. 颜色、边界与阴影

| 用途 | 浅色值 | 使用范围 |
| --- | --- | --- |
| 页面 / 面板 | `#FFFFFF` | 页面与卡片主体 |
| 正文 / 标题 | `#111827` | 核心文字 |
| 说明文字 | `#5B6475` | 描述、帮助信息 |
| 辅助文字 | `#6B7280` | 日期、占位提示；不使用过浅灰色表达必要信息 |
| 主操作 | `#6252E8` | 主按钮、焦点和少量状态指示，延续当前 HitFlare 色值 |
| 主操作悬停 | `#5141D5` | 悬停后略深 |
| 选中浅底 | `#F0EDFF` | 小面积选项高亮，文字仍为黑色 |
| 边框 | `#E4E6EC` | 输入框、卡片、必要分栏，1px |
| 局部浅底 | `#F8F9FB` | 控件悬停、加载占位、小范围分组 |

按钮、输入、选择器、分段筛选圆角统一 8px；内容卡片 12px；弹窗 16px。页签不套胶囊，主导航无外框。上传区域可以使用虚线，其余空状态不套虚线大框。

默认卡片不加阴影，悬停最多 `0 4px 12px rgba(17,24,39,.06)`；普通主按钮最多 `0 2px 6px rgba(98,82,232,.12)`。只有弹窗、浮层需要明显层级阴影，不让所有控件悬浮。页面无点阵背景、无装饰性大渐变；内容图像可自由使用品牌视觉。

保留深色切换：相同尺寸、间距和操作层级，使用集中配置的深色 token；正文、选中项、输入和弹层都须可读。原生画布继续使用 canvasThemes，工作台规范不覆盖其画布底色或节点样式。

## 6. 按钮与输入控件

| 控件 | 高度 | 规则 |
| --- | ---: | --- |
| 页面操作按钮 | 32px | 13px 文字，左右 padding 12px；同组全部等高 |
| 搜索、Select、普通表单输入 | 32px | 左右 padding 10px；文本区域按内容增加高度 |
| 分段筛选 | 总外框 32px | 内边距 2px、选项高 28px；不得再叠加成 36/40px |
| 卡片或表格内图标操作 | 28×28px | 图标 14px；需名称与 Tooltip，不能只有无说明图形 |
| 标签 | 22px 单行 | 12px 文字，长文本可换行；不加重阴影 |
| 生成、登录主按钮 | 40px | 用于主要提交；相关登录输入也为 40px |
| 首页品牌主次按钮 | 44px | 同组等高，文字 14px；不沿用到工具栏 |

主次分工：

- 主按钮：实底蓝紫、白字，每个独立操作区一个主要目标。资产页为「导入资产」，用户管理为「新建用户」，图片页为「生成」。
- 次按钮：白底、细边框、黑字，例如「新增资产」「取消」。通过文字和用途明确操作，不加装饰性线框。
- 轻操作：图标加文字或带提示的图标，无常驻边框，例如「导出资产」、刷新、复制、编辑。
- 危险操作：红色文字、独立位置；确认弹窗保持原行为，不使用普通主操作蓝紫色。
- Hover、按下、禁用、加载、选中和键盘焦点分别定义。焦点环 2px；加载时避免按钮宽度跳变。动画仅颜色与透明度过渡约 150ms，遵循减少动态效果偏好。
- 触屏常用操作的可点击范围至少 40px；不照搬桌面 28px 小点击框。移动端文本输入 16px，避免系统浏览器因聚焦自动放大。

| 我的资产 `/assets` | 第一行左标题说明、右导出/新增/导入；第二行左类型筛选、右搜索；下方网格 | 新增/编辑、预览、详情抽屉、删除确认、导入入口、分页；保持资产包导入现有语义 |

## 8. 响应式与可用性

- 常规页面可用宽度不足 768px 时左右间距改为 16px，页头操作换到下一行；工具区搜索占满一行，保留全部操作。
- 图片三栏和普通卡片网格都依据内容可用宽度响应，不能只判断整个浏览器宽度后让 Agent 面板挤坏布局。
- 资产卡片建议最小宽度 240px，空间不足时减列；缩略图槽位比例统一，图片不拉伸，详情保留原比例。
- 灵感标签在窄屏可折叠，已选状态和清空入口保持可见。表格在窄屏内部横向滚动，页面本身不溢出。
- 标题与说明自然换行；卡片标题可以省略但详情显示完整；必要帮助和错误信息不截断。
- 主体、弹窗、抽屉分别具有明确滚动区域，避免全页面和卡片同时出现无意义双滚动条。

## 9. 确认后的实施与交付要求

1. 先建立共享的容器、间距、排版、颜色、控件尺寸基线；Ant Design 通过 `app-theme.ts` 与 `AppProviders` 配置，原生元素通过少量通用样式接入。复用现有结构，不新增只转发 props 的组件。
2. 按第 7 节逐页处理，并检查每页弹窗、抽屉、下拉、空状态、错误状态及禁用状态；不以完成资产或灵感页代替全站完成。
3. 以 1440、1280、1024、390px 代表视口检查布局；实际浏览器缩放与截图尺寸明确记录，测试结束恢复用户原有尺寸，不关闭用户页面。
4. 逐页确认标题左边界、工具区外框高度、按钮层级、实际内容宽度和换行行为；至少覆盖一组有内容状态与一组空状态，并检查浅色/深色以及 Agent 打开状态。
5. 视觉改造保留生成、API 渠道、本地存储、登录和资产行为。不默认发送付费生成请求；功能验证与视觉验收分开记录。
6. 交付时提供全部入口的覆盖表：已完成、已检查、待用户验收、具体阻塞。存在遗漏或未验页面就直接标明，不表述为全站已完成。
7. 已完成事项移入 pending-test，Changelog 归纳用户可见变化；用户验收后再更新正式功能文档。本轮只记录草案，不把设计意图写成已实现功能。

当前依据：采用 V2 的流式页面边距、18px 页面标题、13px 说明和 32px 桌面工具控件；PC 横屏是主要验收基准，首页和图片工作台按各自内容密度处理。
