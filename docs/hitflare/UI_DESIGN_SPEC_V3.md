# HitFlare 前端界面规范 · V3

给 UI 设计师。本文只定义目标、范围和已经定下的界面规则。它不是开发任务，也不是窄屏改版方案。

状态：结构方案保留，视觉返修。原 [界面交付 V3](UI_DESIGN_DELIVERY_V3.md) 是结构初稿；用户指出颜色与玻璃感不足，最新材料候选与交互样稿见 [V3 视觉复审](UI_VISUAL_REVIEW_V3.md)，尚未验收。不替代以下两份交互依据：

样稿已按 [现网核对记录](UI_LIVE_DESIGN_AUDIT_V3.md) 纠正。字段、控件尺寸、列数和进入方式沿用现网；之前手画的参考图、选图弹窗、模型设置、内容库和预览结构不得直接施工。玻璃材料在真实结构上评审。

- 窄屏布局仍以 [窄屏适配需求](NARROW_SCREEN_IMPLEMENTATION_PLAN.md) 为准。
- 创作 Agent 的对话结构仍以 [Grok Bot Mac 版体验调研](GROK_BOT_MAC_UX_RESEARCH.md) 为准。

[V1](UI_DESIGN_SPEC_V1.md) 已作废。 [V2](UI_IMPLEMENTATION_PLAN_V2.md) 只继续管列表页的页面几何；它里面的「生成按钮也用紫色」和「登录改回白卡片」不再采用。画布编辑器不在本文范围。

## 1. 目标

前端现在有三套同时生效的样子：列表页的 Ant Design、图片和视频工作台里手写的 GrokBot 样式、创作 Agent 里另一套对话结构。标题字号、按钮高度、圆角和主色不统一。同一颗白圆按钮在六个文件里各写一份。

目标是一份现在仍然有效的界面规范，再把已经复制的控件收成少量共用组件。

不是这些事：

- 可以参考 Ant Design X 的对话结构，例如气泡、输入条、思考过程。不把它加进依赖，也不按它的默认紫皮重画创作 Agent。其他外部聊天组件库同样只作参考。
- 不把全站收成同一种样子。列表页不要改成聊天气泡，工作台也不要改回紫色主按钮。
- 不重画页面流程，不改信息架构，不新做一套动效。
- 不在这轮重排画布编辑器，也不重做窄屏方案。

## 2. 建设范围

建设内容是一份规范，加上少量共用组件。规范分成五层。前四层要写完整；手感只记录控件反馈。

| 层 | 要写清的内容 | 这轮怎么处理 |
| --- | --- | --- |
| 基础 | 颜色、字号、间距、圆角、阴影、图标、叠放 | 两套颜色分开写，不再出现临时值 |
| 布局 | 页面用哪种外壳、内容怎么对齐、区域怎么分、弹层怎么贴边 | 只定模板，不把每个页面重画一遍 |
| 组件 | 按钮、输入、选择、胶囊、气泡、方案卡的尺寸和状态 | 写规则；只抽已经复制的控件 |
| 反馈 | 空、加载、错误、成功、禁用 | 补齐。现在各页各做 |
| 手感 | 悬停、按下、焦点，以及创作 Agent 已经定过的动效 | 只记录现有反馈，不新做动效语言 |

### 2.1 要抽成共用组件的

- 普通白圆图标按钮。图片、视频、反推、场景模板、资产、灵感详情中重复的同类轻操作收成共用组件；现有 32px 圆、16px 图标和 13px / 20px 文字可复用。返回的 36px 和图片预览的 40px 保留，不套用 32px，也不为统一而重画图标。
- 工作台设置里重复的黑色选中胶囊和圆角输入。图片、视频、音频、文本设置面板已经是同一套，收成共用样式。
- 列表页标题继续用现有的 `workspace-title`，不另做一套标题组件。

### 2.2 只写规则、不抽成通用库的

创作 Agent 的历史栏、标题胶囊、气泡、输入框、方案卡仍留在现有文件里。规范记录它们的尺寸和状态，避免以后再长出变体。不要做成可配置的通用聊天组件。

### 2.3 这轮不建设

- 画布编辑器 `/canvas/:id` 的节点、工具栏和画布主题。
- 画布列表现在的 `max-w-6xl`。它和「列表页不设最大宽度」冲突，先标成例外，这轮不重排。
- 窄屏断点、顶栏、记录、资产时间轴已随 v0.18.8 / v0.18.9 上线。设计师不要改回圆形 Logo，不要去掉内容库的来源筛选和收藏，不要把模型参数画回左上角弹出。已发布细节以任务分工和线上为准。
- 新页面、新流程、新图标库、新字体。

## 3. 两套外观

两套外观各自只管自己的页面，不要合成一套假的「全站 GrokBot」。

本节保留原结构方案的尺寸与颜色基线。颜色、透明度、描边和阴影的返修候选以 [V3 视觉复审](UI_VISUAL_REVIEW_V3.md) 为准，评审后再回填本节；以下纯色值不表示返修后的最终材料。

### 3.1 列表、后台

使用现在的 Ant Design。

适用页面：我的资产、创作灵感、用户管理、日志、存储。配置不在这套里。

页签选中用近黑，不用紫色下划线。紫色只出现在主按钮上。

- 页面标题 18px / 26px，字重 600。
- 标题下的说明 13px / 20px，颜色 `#5B6475`，最长约 70 个字符，左对齐。
- 分组、弹窗、抽屉标题 16px / 24px，字重 600。
- 导航、正文、一级页签 14px / 22px。
- 说明、表单标签、按钮、搜索、筛选 13px / 20px。
- 日期、数量、辅助信息 12px / 18px。
- 普通按钮、搜索、输入、选择器高 32px，圆角 8px。
- 主按钮是紫色 `#6252E8`，悬停 `#5141D5`，白字。每个独立操作区只有一个主按钮。
- 次按钮白底、1px 边框 `#E4E6EC`、黑字。
- 轻操作无常驻边框，悬停才有浅底。
- 危险操作红色文字，删除仍走确认，不把删除做成紫色主按钮。

Ant Design 的全局主色现在是近黑 `#171717`，紫色只加在按钮上。保持这个分工：紫色不铺到链接、正文和页签。

### 3.2 工作台和创作 Agent

沿用已经定下来的 Grok 样式。

适用页面：图片创作、视频创作、反推提示词、创作 Agent、配置。配置从创作流程里打开，继续用这套黑按钮和全圆角输入，不要改成后台的紫按钮。

- 正文、按钮、说明都是 13px / 20px。工作台不出现 18px 页面标题。
- 主操作是黑色 `#111827`，白字，高 40px，全圆角。不要改成紫色。
- 白圆图标按钮：32px，白底，图标 `#6B7280`，轻阴影 `0 1px 2px rgba(16,24,40,.06)`。旁边的文字是 `#374151`。
- 输入和选择沿用现有圆角、36px 或 40px 高度。同组表单对齐边界；轻操作图标可在较高输入旁垂直居中，不因“同行同高”强制把 32px 图标放大或把 36px 配置控件增高。
- 选中项用黑底白字胶囊。未选中是 `#F3F4F6` 浅底，悬停 `#E5E7EB`。
- 正文黑 `#111827`，次级文字 `#6B7280`。蓝紫色不用于工作台正文和主按钮。

## 4. 字号

只保留下面这些层级。灵感分类标题现在的 15px、设置面板里临时的 15px，都收回对应层级，不再保留 15px 这一档。

| 用途 | 字号 / 行高 | 字重 | 用在哪 |
| --- | --- | --- | --- |
| 首页品牌标题 | 桌面 48 / 60，窄屏 32 / 42 | 600 | 只在首页品牌区 |
| 首页区域标题 | 24 / 32 | 600 | 只在首页 |
| 列表页标题 | 18 / 26 | 600 | 资产、灵感、用户、存储；日志保留现有 16px，配置弹窗沿用自身标题 |
| 分组、弹窗、抽屉标题 | 16 / 24 | 600 | 列表页的分组和弹层 |
| 资产详情标题 | 16 / 24 | 600 | 只在资产详情 |
| 导航、正文、一级页签 | 14 / 22 | 400，选中 500–600 | 列表页和导航 |
| 说明、按钮、表单、气泡正文 | 13 / 20 | 400 | 两套外观都用 |
| 资产详情的提示词、标签、元数据 | 13 / 20 | 400 | 只在资产详情 |
| 日期、数量、资产详情底部操作 | 12 / 18 | 400 | 辅助信息 |

不下载新字体，不加全局字距。首页品牌标题已有的轻微负字距只留在首页，不扩散。

## 5. 页面布局

布局写进规范，但只定五种模板。设计师按模板整理，不要为每个路由重画一版。

每种模板同时画出宽屏和窄屏。两种宽度的布局可以不同，例如宽屏左右分栏、窄屏改为上下或全屏记录。不要只画桌面，再把窄屏另写成一份清单。

宽屏验收以 1440×900 和 1920×1080 为准。窄屏沿用已有断点，不在这里另定断点。进入方式以窄屏文档为准。

### 5.1 列表页

资产、灵感、用户、日志、存储使用现有 `workspace-page`。配置是弹窗，控件用工作台外观，不套这套列表模板。

- 左右边距沿用现有 `clamp(24px, 2cqi, 48px)`，上 20px，下 24px。
- 不设全站最大宽度。宽屏用来多放卡片和表格列。
- 标题和左侧导航共用左边界，页面主操作在标题行右侧。
- 标题和说明相距 4px。标题区与下一行相距 16px。筛选或工具条与内容相距 16px。
- 长说明限制在约 70 个字符宽。单列表单最宽 640px。这些限制不套到整页上。
- 卡片网格间距 16px。同组按钮间距 8px，图标和文字间距 6px。

### 5.2 工作台

图片、视频、反推占满导航右侧的可用宽度，不套 `workspace-page`，也不再写一个页面大标题。

- 宽屏是左右分栏。图片页左侧设置栏宽 320–380px，右侧是结果。达到 1100px 才分栏。
- 历史记录在宽屏留在侧栏，不做成底部抽屉。窄屏如何进入记录，以窄屏文档为准。
- 结果里的图片保持原始比例，不拉成横条。

### 5.3 对话

创作 Agent 是左右两栏。

- 左侧历史顶到区域上沿，只有圆形搜索和圆形新建，没有「新对话」文字，也没有「今天 / 更早」分组。
- 右侧对话自己滚动。输入框始终留在右侧底部。
- 标题是居中的白胶囊，不是通栏。打开方案时，胶囊换成方案名，左侧关闭，右侧分享，历史栏不动。
- 方案先出现在对话流里。点开后占满右侧，不另开一块浮动卡片。

具体的气泡、图片预览和输入框形态，以 Grok Bot 调研文档和现有创作 Agent 页面为准，不要按通用聊天模板重画。会话头像用 Grokbot 黏土机器人，造型从 Grok Bot Studio 生成，不以现有色块简图为准；出处和示例链接写在调研文档里。

### 5.4 首页

首页单独保留品牌大标题、区域标题和内容限宽。内容区现在最宽 1320px。品牌区不套列表页标题。三个场景入口保持卡片，不要因为数量少拉成通栏。

### 5.5 登录

按现在的深色聚焦页记录：右侧深色玻璃卡片，最宽约 380px。不要退回旧规范里的白底 400px 登录卡。

### 5.6 弹层

弹层算布局。对话框、抽屉、下拉、图片预览必须规定宽度和贴边，不能每页各写一个。

已经定下的：

- 列表页弹窗圆角 16px，标题 16px。
- 创作灵感详情在宽屏保持现在的 720px；窄屏铺满视口，以窄屏文档为准。
- 图片预览分两套，都全屏、居中，点空白或 Esc 关闭。审读预览给生成图，深色遮罩，右上是收藏、下载、存入资产、关闭。轻度预览给参考图和内容库图片，浅遮罩，右上只有关闭。两套底部都有翻转、旋转、缩放。窄屏不画左右切换，多图只用底端缩略图。
- 模型配置是居中小弹窗，约 440px，内容在弹窗内滚动。不要画成贴边的气泡。
- 参考图里的选择资产是独立弹窗：来源页签和「我的收藏」，点图进轻度预览，添加按钮在图片底部内侧。不要和内容库页面、也不要和按类型翻页的素材选择画成同一个。
- 渠道和来源抽屉的窄屏宽度不超过屏幕，标题单独一行，取消和保存移到底部。

还需要设计师收口、但不要新发明样式的：

- 列出现在每个对话框和抽屉的宽度，优先复用相同用途的尺寸。保留模型参数 440、参考图选择资产 760 等现有宽度；先验证字段和内容密度，再决定哪些档位可合并，不为减少数值而强行加宽或缩窄。
- 下拉和气泡菜单沿用 Ant Design 的弹层底色，不在单个菜单上另配颜色。

## 6. 组件形态

同一类操作只有一种样子。

| 组件 | 列表、后台 | 工作台、创作 Agent、配置 |
| --- | --- | --- |
| 主按钮 | 高 32px，圆角 8px，紫底白字 | 生成和发送高 40px，全圆角，黑底白字 |
| 次按钮 | 高 32px，白底细边框 | 不另做第二套主按钮 |
| 轻操作 | 透明底，悬停浅底 | 白圆图标加 13px 文字 |
| 输入、选择 | 高 32px，圆角 8px | 沿用现有 36/40px，同组表单对齐，轻操作图标可居中 |
| 分段选择 | 外框高 32px，内边距 2px | 黑底白字胶囊，未选中浅灰底 |
| 卡片 | 圆角 12px，默认无阴影 | 方案卡白底，底部是方案名芯片 |
| 标签 | 单行约 22px，文字 12px | 不另做彩色标签体系 |

图标继续用现有的 Lucide，导航和工作台图标 16px，列表页工具图标 14px。灯箱里已经在用的 Ant Design 图标先保持，这轮不强制换成 Lucide。不新增图标库。

## 7. 反馈

反馈要补进规范。空、加载、错误、成功、禁用在两套外观里各写一种，不按页面现写。

- 空状态：一个 16px 图标、一句 13px 说明、最多一个操作。不要大块虚线框，不要整页灰底。
- 加载：按钮内用现有转圈，按钮宽度不跳。工作台生成中的状态沿用现在的软圆点，不改成另一套骨架屏。
- 错误：文字说明放在操作附近，不用只靠颜色。删除和不可逆操作继续用确认框。
- 成功：沿用现在的轻提示，不新做顶部通知中心。
- 禁用：分别定义表面、字色和边框，仍能辨认文字；不统一降低整颗控件的透明度。最终数值随组件状态板定稿。

资产卡片现在的上浮、放大和蓝色投影不是标准。列表卡片悬停最多用很轻的阴影，不上浮，不加蓝色光。

## 8. 手感

包括手感，但只收控件本身的反馈，不重做页面体验。

两套外观共用：

- 悬停只换底色或边框色，颜色过渡大约 150 毫秒。
- 按下不位移，不加放大。
- 键盘焦点可见，焦点环约 2px。
- 禁用用透明度。
- 遵守系统的「减少动态效果」。用户打开后，悬停位移和循环晃动都停掉。

只属于创作 Agent、已经定过、不要重画的：

- 点标题时，图形先压扁再弹起，箭头从右侧滑出。
- 思考或出图时，图形左右轻晃，不使用转圈代替。
- 输入框没内容时是一行。写了字或加了图后，高度固定，文字在框内滚动，图片在文字上方。

不纳入规范的手感：页面切换动画、滚动惯性、音效、卡片上浮、蓝色投影、新的品牌动效。

## 9. 设计师要交什么

按本文整理一版可交付的界面说明，包含：

1. 两套外观的基础样式：颜色、字号、间距、圆角、阴影。浅色和深色都要有。
2. 五种页面模板，每条一张，图中同时包含宽屏和窄屏。布局不同就画两种，不按每个菜单页各画一张。
3. 组件状态：默认、悬停、按下、焦点、禁用、加载、选中。主按钮、白圆按钮、输入、分段、弹层各一组。
4. 反馈：空、加载、错误、成功各一种。
5. 弹层宽度收口：把现有对话框和抽屉归进少数几档。

不需要重画的：

- 创作 Agent 的对话结构。对照现有页面和 Grok Bot 调研即可。
- 窄屏不单独交一份方案。它画在同一张模板里，进入方式对照窄屏文档。
- 画布编辑器。
- 新的业务流、新的导航项、新的空状态插画。
