公网入口实际引用 `index-Ekhs99d-.js` 与 `index-Do32o6QI.css`，对应仓库的 v0.18.9 发布包。发布说明中“尚未部署”的文字已滞后，不能据此判断现网；本次以公网资源和实际浏览为依据。当前本地源码还包含未进入这份包的修改，不能把它当作全部线上事实。

截图和渲染结构保存在 `design/live-audit/`。评审入口仍为 [glass-review.html](design/glass-review.html)。新底稿保留线上 DOM、样式、图标、控件和字段；移除业务脚本，图片替换为本地示例，不读取线上账号或媒体接口。两种材料套在同一结构上。示例图片、日期、模型值是状态示例，不是新的默认值。

## 现网与已确认目标的差异

**内容库窄屏直接点图，目前仍打开审读预览。** 实际能看到“收藏、下载图片、存入资产、关闭”；而宽屏先进入资产详情，再点大图是只有关闭的轻度预览。参考图选资产中的轻度预览也正常。

这不是新的设计决策。已确认目标仍是“内容库图片用轻度预览”；本地源码已写 `variant="light"`，与当前发布包行为不同。开发需核对这项是否进入部署产物。设计底稿的“线上基线”保留观察结果；玻璃候选中的窄屏内容库预览按已确认目标仅保留关闭。不能再写成线上已验收完成。

窄屏顶栏当前页入口仍靠近 Logo，未达到前端反馈的“剩余空间正中”；本次沿用现网截图作基线，不以样稿假装这项已上线。已确认的居中目标保持不变。

- 旧 `glass-scene.html` 和七场景图片撤回为页面依据，不再用于前端还原。原九张结构图也不是最终视觉稿。
