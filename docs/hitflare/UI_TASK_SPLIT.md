# 界面任务分工

一份方案同时覆盖宽屏和窄屏。同一页可以有两种布局，不把宽屏、窄屏拆成两份清单，也不另做一套流程。

v0.18.8 和 v0.18.9 已经发布的窄屏行为，以线上为准。下面若和旧描述冲突，按已发布的写。

依据：

- 布局与进入方式：`docs/hitflare/NARROW_SCREEN_IMPLEMENTATION_PLAN.md`
- 外观：`docs/hitflare/UI_DESIGN_SPEC_V3.md`
- 创作 Agent 结构：`docs/hitflare/GROK_BOT_MAC_UX_RESEARCH.md`

宽屏看 1440×900 和 1920×1080。窄屏沿用已有断点：顶栏小于 960px，工作台小于 1100px，列表页小于 767px。弹层读不到页面容器时，用视口 767px。不新增全局断点。

## 设计师

结构初稿已交，视觉返修，尚未验收。原九张图不足以表达通透玻璃感；本次交付 [V3 视觉复审与可操作样稿](UI_VISUAL_REVIEW_V3.md)，同时展示宽窄与浅深色。下面勾选按最终设计交付计算，不能用结构占位图或文字规则代替。正式头像示例仍未交付。

最新 [现网核对记录](UI_LIVE_DESIGN_AUDIT_V3.md) 已指出并纠正手画样稿的结构偏差。评审入口已改为线上渲染底稿；材料候选不得变更字段、图标、尺寸、列数或入口。内容库窄屏预览及顶栏居中与开发反馈仍有发布差异，不能按下方勾选理解成线上验收通过。

每种模板一张，图里同时画出宽屏和窄屏。布局不同就画两种，不要只画桌面再写一句「窄屏另看」。

- [ ] 基础样式：两套外观的颜色、字号、间距、圆角、阴影。浅色和深色都要有。宽屏窄屏共用，不另写字号。
- [ ] 列表页。宽屏是标题、搜索、筛选和网格或表格。内容库窄屏去掉搜索、数量、更多操作和宫格切换，保留来源筛选和收藏，按时间轴看图。创作灵感窄屏去掉搜索，封面写死两列。
- [ ] 工作台。宽屏是设置栏、结果和左侧历史。窄屏是上下单列，返回进入记录，记录不盖住顶栏。
- [ ] 对话。宽屏是历史栏加对话。窄屏标题胶囊居中，最长约 14rem，不压住返回和分享。参数按钮只留图标。
- [ ] 首页和登录。两种宽度都要有。只收边距和排列，不改品牌结构。
- [ ] 组件状态：默认、悬停、按下、焦点、禁用、加载、选中。主按钮、白圆按钮、输入、分段、弹层各一组。
- [ ] 反馈：空、加载、错误、成功。两套外观各一种。窄屏可以改排列，不换另一套文案样式。
- [ ] 弹层。宽屏收成少数几档宽度。窄屏可以改成铺满，或改成底端缩略图，不沿用宽屏的左右按钮。
- [ ] 会话头像按 Grok Bot Studio 出示例：<https://grokbots.ai/studio?face=excited&shape=cloud>。同一会话一个造型。

边界：列表页和后台用 Ant Design，主按钮紫色，页签选中近黑。图片、视频、反推、创作 Agent、配置用工作台外观，生成和发送是黑按钮。配置不要画成后台紫按钮。创作 Agent 的对话结构不重画。画布编辑器不重画。不新做空状态插画和卡片上浮。

## 前端

按同一页的两种布局做。前端已反馈本批宽窄布局完成，组件抽取未做。下面布局项的勾选表示开发反馈已完成，不表示设计师逐页验收。宽屏不是另一批页面，是同一页在宽断点上的布局。

- [x] 顶栏。窄屏用透明底玻璃黑长 Logo，不是圆形标。左边距和页面内容对齐，左右留白至少 24px。当前页下拉在剩余空间居中，点开是圆角浮层。设置、语言、主题、改密、退出在下拉里，右侧不再放用户名圆标。宽屏仍是左侧竖栏，用户圆标显示名字前两个字。
- [x] 图片、视频、反推。窄屏用返回进入记录，返回、搜索、新建在同一行。记录不盖住顶栏。宽屏用左侧历史栏，不出现返回。模型参数从屏幕正中弹出，放不下时在弹窗内滚动。
- [x] 大图分两套，不要画成同一种。审读预览用于生成图：图片创作结果、Agent 方案图、画布生成图。深色遮罩，右上是收藏、下载、存入资产、关闭。轻度预览用于参考图和内容库图片：浅遮罩，右上只有关闭。点遮罩或 Esc 都能关。两套都可翻转、旋转、缩放和拖动，且不改原图。窄屏都不显示左右按钮，多图只用底端缩略图；宽屏审读预览保留左右按钮。
- [x] 资产。窄屏去掉搜索、数量、更多操作和宫格切换，只按现有时间轴展示。来源筛选和「我的收藏」两种宽度都保留。不再按模态筛选。点内容库图片走轻度预览，不走审读预览。文字、视频、音频仍进详情。宽屏保留搜索、数量、更多操作和宫格。日期仍是「2026年10月31日 · N 项」。
- [x] 模型配置。图片、视频、反推、Agent 都用居中的设置弹窗，宽约 440px，不超过视口。内容放不下时在弹窗内滚动，不贴左上角。
- [x] 参考图的选择资产。图片创作和 Agent 用这一套：来源页签加「我的收藏」，按日期滚动加载，点图是轻度预览，添加是贴在图内底部的浅黑胶囊。画布、视频、反推的选择资产仍按类型翻页，并保留搜索。
- [x] 创作灵感。窄屏两列封面，不显示搜索，详情铺满。宽屏是大卡片和 720 宽弹窗。两列要写死，不能靠最小 240px 的自动网格。
- [x] 配置。窄屏取消和保存放到底部。宽屏仍放在右上角。表单字段不改。
- [x] 画布列表。按钮在窄屏必须换行。不改画布编辑器。
- [x] 管理日志。筛选已改成下拉，主筛选一行换行，更多筛选另起。不再按旧的五列网格在 640px 切列。标题 16px，筛选和表格 13px。详情窄屏不超过视口。
- [x] Agent。窄屏标题胶囊居中，最长约 14rem 后截断，不压住返回和分享。参数按钮只留图标，和输入框、发送同一行。宽屏仍显示完整参数。历史和方案结构不改。

外观和共用组件按已定稿的组件组逐批落地；每组的材质、尺寸、状态及代表页面确认后即可开工，不要求全部模板同时交齐。不单独再开一轮只改宽屏的页面重排。

- [ ] 白圆图标按钮收成一个。工作台的选中胶囊和圆角输入收成共用样式。
- [ ] 列表卡片去掉上浮、放大和蓝色投影。
- [ ] 配置继续用工作台黑按钮。页签选中不用紫色。

不做：引入 Ant Design X，重做创作 Agent 对话结构，重排画布编辑器，把全站收成一种样子，新断点，视频单独灯箱，手势拦截。

## 下一步推进顺序

1. **前端先完成现有码收尾，同时设计继续交付。** 静态复核发现 `asset-picker-modal.tsx` 的通用 `MyAssetsTab` 使用了 `Search` 图标却未导入，应先修正并验证画布、视频、反推的选资产入口。`app-side-nav.tsx` 当前用整条顶栏的绝对定位居中，与“Logo 右侧剩余空间居中”不同，Logo 外还有带底色和边框的胶囊，需要按已确认目标复核。二者是当前代码检查结果，未据此声称在最新本地运行页复现。
2. **设计先交一组可实施的样板。** 图片工作台、内容库、模型设置、参考图选资产、轻度/审读预览沿用线上结构。材质修订为更透的浮层，生成按钮保持实色黑；七态和四种反馈在评审页「控件状态」。待用户看过这一版后再交给前端，不在这一轮改业务样式。
3. **前端随定稿抽取重复样式，设计并行补全。** 先处理重复白圆按钮、选中胶囊、圆角输入与弹层外壳；现有共用组件直接复用。设计继续完成 Agent、灵感、配置、后台及首页/登录的模板与二级状态，头像独立交付，不阻塞基础组件。每批同时包含宽窄与浅深。
4. **按完整使用路径验收并交发布。** 核对添加参考图→选资产→预览→返回，生成记录→结果→审读→存入内容库，灵感详情→复制/加入资产，Agent 对话→方案→返回，以及配置保存/取消。同时看滚动区域、底部操作、长标题、键盘焦点与窄屏触控；需要真实生成的项目另列实际验证状态。发布包明确包含哪些本地改动，发布后复核同一组路径。

本轮只整理设计与推进计划，没有修改业务实现、构建或部署。产品 TODO/Pending Tests 不新增“已开发待测”项；已有服务化和反推专项验收继续按原清单推进，新产品方向独立讨论。
