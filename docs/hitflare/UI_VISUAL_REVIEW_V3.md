# HitFlare V3 视觉复审与通透材质样稿

状态：设计方向返修，待用户评审。前端布局已由开发反馈完成；本次交付设计文档和独立样稿，不代表业务页面已修改或验收。

本次已对照实际线上页面纠正样稿，详见 [现网核对记录](UI_LIVE_DESIGN_AUDIT_V3.md)。旧手绘场景改变了参考图、模型字段、选图列数和操作位置，已撤回作页面依据。当前评审使用线上渲染结构与图标，玻璃候选在同一结构上调整材质。

## 结论

上一版交付适合解释结构，不足以指导最终视觉。用户认为颜色和玻璃感不够，问题成立：原稿把颜色当成实色填充，把层次当成边框，把组件状态当成一排色块。品牌素材本身有光泽和通透感，控件却没有同一套材质逻辑。

保留现有白色创作主体、列表紫色主操作、工作台黑色生成/发送、宽窄布局与进入方式。视觉方向改为：**清晰的内容底 + 轻透的玻璃工具条 + 透色但可读的弹窗**。色彩主要来自用户作品和既有品牌素材。

## 2. 材质怎么用

### 三种层次

| 层次 | 视觉效果 | 用处 | 不用在 |
| --- | --- | --- | --- |
| 内容底 | 白底/中性深底，文字和图片不透明 | 页面主体、长提示词、输入、表格、图像本体 | 不为了展示玻璃铺全屏彩色背景 |
| 轻透玻璃 | 能透出背后色彩，细亮边，轻阴影 | 返回/关闭圆按钮、标题胶囊、悬浮工具条、图片内添加按钮 | 不给每张内容卡片都套一层玻璃 |
| 表单玻璃 | 更实的底色，只透出低频色彩，文字稳定 | 模型参数、选择资产、菜单、抽屉外壳 | 不把整段正文、所有表单控件降低 opacity |

页面上的连续阅读区保持清晰。大图上方和下方的控件可以明显透光；大图本身不模糊、不调色、不透底。图片内“添加”保留浅黑半透明胶囊，以兼容亮图和暗图。

已有的 8 / 12 / 16 / 全圆角体系可继续使用。玻璃感主要来自背景透色、边缘高光和适当阴影，不靠把每个框变得更圆。

玻璃表面另叠一层很轻的斜向明暗，高光集中在边缘；没有彩虹渐变、厚白边或蓝紫色外发光。

阴影跟用途走：

- 工具条：`0 8px 28px -12px rgba(18,23,32,.22), 0 1px 3px rgba(18,23,32,.06)`。
- 表单：`0 26px 80px -24px rgba(18,23,32,.32), 0 3px 12px -4px rgba(18,23,32,.10)`。
- 深色分别使用中性黑阴影，边界主要由低亮度高光表达，不加彩色光晕。

背景只有白色时，玻璃效果应当克制。样稿“材质近看”用现有登录品牌图测试透光，不表示将这张图铺到工作台背景。

### 主操作与状态

- 列表主按钮继续用既有紫色，32 高、8 圆角。深色用既有较浅紫色；不把页签变紫。
- 工作台生成/发送仍为 40 高实色黑胶囊，不改成半透明，也不再用石墨渐变。只保留 1px 上沿高光。深色反转为浅色实色主按钮。
- 普通轻操作沿用现有 32×32，返回保留 36×36；预览顶部圆按钮为 40×40，弹窗关闭沿用原形状。不能把这些控件一律缩成 32。所有图标、文字保持不透明。
- 禁用候选采用次级中性底色、明确的次级字色，无投影、无悬停响应；整体 opacity 保持 1。不同底色下分别检查文字，不统一用 40% 压低整颗控件。
- 聚焦仍需清晰的 2px 轮廓；悬停只微调表面，不位移、不放大。
- 整套七态与空/加载/错误/成功的浅深色状态板仍待定稿。本次材质样稿不冒充完整状态交付。

- 原有九张 SVG/PNG 和手绘 HTML 保留作档案，不能据其还原字段、尺寸、列数或进入方式。
- 本次在内置浏览器检查新底稿九个场景的 1440×900、390×844 两种画板及浅深主题，没有整页横向溢出或破图。模型弹窗分别为 440/358，选择资产为 760/366；选图四列/两列正确。预览按钮与图标使用真实结构，不再统一重画。
- 已检查选择资产→单图轻度预览→返回、模型弹窗开关、审读缩略图切换；单图无计数和画廊。窄屏两种预览无左右按钮，宽屏仅审读保留。其他业务入口仅展示状态或提示，不声称完整交互验收。
- 文字与图像不随容器降透明度；图片亮暗变化时检查操作区可读性。
- 模糊只加在需要它的容器，避免同一区域叠多层背景模糊。表单遮罩不再额外加一层模糊，以便窗体对页面本身取样。
- 产品实施时，减少透明效果或不支持背景模糊应使用可读的不透明中性表面，减少动态效果应关闭过渡。这些跨浏览器与辅助功能降级仍需专门验证，本次不记作通过。
- 样稿检查不等于产品在 Safari、真实移动设备或完整可访问性验收；真实数据、键盘焦点循环、触控与性能仍需在产品实现阶段验证。
- 本次未改业务源码，未执行业务构建或生产部署。产品 TODO 与 Pending Tests 没有新增实现项，因此不把本次样稿写成“已开发待测”。
