01 / 扁平，不靠阴影凸起

控件没有投影和高光。状态只换填充。参数条保持原来的白底胶囊和细边，只留很轻的投影。参考图空态加号沿用这一套，尺寸仍是 64 方块。

02 / 实色的东西继续实色

生成按钮、选中胶囊、提示词和输入框不透明。禁用只换字色和底色，不把整颗控件淡掉。焦点是 2px 近黑轮廓，不用紫色。

03 / 这还不是全套

这一组只覆盖图片工作台、内容库、模型参数、参考图选资产和两种预览。灵感、配置、后台、首页和 Agent 头像还没画。不是施工单。

“线上基线”保留线上渲染结构与样式，图片换为仓库示例；不是完整业务应用。记录截图在 live-audit/，差异清单见 UI_LIVE_DESIGN_AUDIT_V3.md。宽屏画板支持 1440 / 1920，窄屏 390。切换场景用于设计评审，生成、添加、保存均不执行真实操作。
